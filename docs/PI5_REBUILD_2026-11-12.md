The 2.8 mm OV5647 module has manual optical focus. The first verified frame was
electrically valid but visibly out of focus. Adjust the lens ring in small
increments while the live page is open; software sharpening is not a substitute
for optical focus. The page has display-only rotate and mirror controls.

The temporary service is installed as `apex-camera-test.service` and starts at
boot. Useful commands:

```bash
systemctl status apex-camera-test.service
sudo systemctl restart apex-camera-test.service
sudo systemctl disable --now apex-camera-test.service
```

Before enabling the production `apex-meta1.service`/AI HUD, disable this test
service. Exactly one process must own the CSI camera and port 8888.

## Power finding

The PMIC reported `EXT5V` around 4.824–4.835 V. Two short undervoltage events
were logged during each observed boot, after which voltage normalized. A
20-second four-core SHA-256 load and the 1080p camera stream produced no new
undervoltage event, but the boot-time events remain a wiring/PD warning to fix
before sustained AI + mapping load.

Check after each power-path change:

```bash
vcgencmd pmic_read_adc | grep EXT5V_V
vcgencmd get_throttled
journalctl -b -k --no-pager | grep -Ei 'under.voltage|voltage|throttl'
```

For a clean boot with no undervoltage history, `vcgencmd get_throttled` must
return `0x0`.
